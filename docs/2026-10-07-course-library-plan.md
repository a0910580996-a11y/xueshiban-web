# 学事板课程资料库改版计划

目标：从公告列表改为课程学习入口，保留作业、通知、管理员发布与设备本地状态；不改变免费静态托管架构。

## 已确认设计与边界

- 固定本学期 11 门课程，其他已识别课程放入大二其他课程，不假设其具体学期。
- 原件不改不删。哈希相同只存一个附件，同名不同内容保留不同版本。
- 个人作业、个人信息、整本教材、公开权限不明、内容无法检查的文件不公开。清单与全文检查结果只在被忽略的 `.work/`。
- 课程、用途、格式组合筛选；按需展开课程入口；搜索覆盖课程名称、标题、附件名称；分批展示资料。
- 新视觉为纸感校园编辑风格：大标题、独立操作区、紧凑资料行、图片留在边缘。动画不挡点击，遵守减少动画偏好。
- 保持 schemaVersion 1；资料新增可选 subject，旧内容兼容。管理员资料发布支持课程字段。

## 实施与验收

1. 本地 ZIP 盘点：路径安全、解压与 SHA-256 去重，生成逐文件原路径、哈希、处理理由清单；嵌套 ZIP 独立检查，不执行代码或宏。
2. 测试先行：课程目录含 11 门固定课；资料可按课程与类型过滤；搜索匹配附件名；错误字段拒绝；公开附件真实存在。
3. 最小实现：`courses.js` 负责课程目录与别名，`domain.js` 负责筛选校验，`app.js` 负责课程浏览与详情，`styles.css` 重构视觉，`scripts/` 保存可复用整理逻辑。
4. 内容检查：DOCX 原 XML 与 PDF 全文检查；旧 DOC、扫描件、嵌套 RAR 等不能充分检查时留待确认，不用文件名代替全文验收。
5. 本地 npm test、语法检查、手机和桌面浏览器实测课程入口/组合筛选/搜索/资料打开/作业完成/通知已读/管理员表单。原有空数据不得伪造成真实作业。
6. 只发布候选审查通过的文件；读取远端 main 确认无冲突后快进合并、push，等待 Pages 部署，并检查公开站点及至少一个实际附件。

完成后交付：公开网站链接、实际入库数量、待确认数量、去重依据、验证结果和下一步。
