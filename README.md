# 学事板 Web

手机和桌面浏览器可用的静态学事板。作业、通知、资料通过 `content.json` 发布；无独立数据库和服务器。班级只做筛选，完成和已读状态保存在当前设备。

## 本地运行

在本目录执行 `npm start`，访问 `http://127.0.0.1:4173`。`npm test` 检查筛选、截止时间、链接安全与发布冲突处理。

## 发布及管理

仓库 `a0910580996-a11y/xueshiban-web`，GitHub Pages 从 main 根目录部署。只上传本目录，不上传小程序配置、云函数凭据或历史材料。

网站的管理入口使用 GitHub Fine-grained personal access token，仓库范围只选择本仓库，Contents 授予 Read and write。授权仅在内存中使用，刷新页面即退出；不写入本地存储。多管理员通过各自 GitHub 账号和仓库权限协作，原微信管理账号不会自动迁移。

发布正文与附件以一次 Git commit 更新，分支更新禁用 force，防止并发发布覆盖。已发布、草稿和撤回内容都会存储在公开仓库，草稿只表示网站列表未展示，不能用于私密内容。撤回不删除 Git 历史，附件旧链接也仍然公开。避免上传个人信息、考试保密材料及无权分发的内容。

单次最多 3 个附件，每个 20 MB；PDF、Word、PPT、MD 和图片。不要长期把仓库当大文件网盘；大规模附件增长后需重新选择存储方案。Pages 部署有延迟，不能承诺即时生效。国内微信浏览器和移动网络的可达性待实际验收。

## 迁移边界

当前资料库已从用户提供的大二资料包导入首批 42 条资料、44 个附件。没有虚构班级作业和通知。旧微信云数据库及 cloud:// 附件尚未迁移；需要通过原云环境导出公开业务字段、下载附件，转换为此站点的结构，不导出管理员密码、会话或恢复密钥。旧数据验收通过以前，保留旧小程序及云服务。

迁移工具：`node scripts/import-cloud-export.js 导出汇总.json 附件映射.json`。汇总文件含 `homeworks`、`notices`、`materials` 三个数组；映射文件把旧 `cloud://` 文件标识映射为新的 `files/文件名.pdf` 或 HTTPS 地址。工具只复制业务字段，遇到未迁移附件会停止，输出到被 Git 忽略的 `.work/migrated-content.json`，不覆盖已有输出、不自动发布。审查内容和附件后再将结果用于正式迁移。材料中未通过旧内容安全检查的记录只迁移为草稿。

现版本提供作业列表/详情/完成标记/班级筛选/搜索、通知分类和已读、资料分类/预览或下载/分享、GitHub 管理发布/草稿/编辑/撤回/备份。微信专有登录、微信管理员账号管理、自习隐藏入口、跨设备状态同步与自动内容审核不在此首版中。

## 2026-10-07 界面与筛选迭代

通知只保留课程通知和考试通知。作业可按课程筛选，按截止日期由近到远、由远到近或课程名称排序；与状态、班级、搜索组合使用。Ctrl+K / Cmd+K 聚焦当前板块的搜索框，管理员表单和打开的详情弹窗不拦截该快捷键。

第二版采用纸感校园编辑风格：全页水彩背景配浅色阅读面板、课程卡片与紧凑资料行。背景为内置 imagegen 生成的真实位图，提示词强调现代校园、阅读空间、暖白留白、鼠尾草绿和浅赭色，不含文字与人物；只做 JPEG 编码压缩，原 PNG 在本地保留。CSS 只负责布局、遮罩与轻微过渡，不绘制背景。背景不接收点击，动画支持减少动态偏好。

网站未绑定自定义域名。GitHub Pages 默认域名包含仓库所属账号；独立域名需要实际拥有域名并设置 DNS，不能只修改网页标题来改变地址。

## 课程资料库与整理流程

作业发布与编辑增加“提交平台”：学习通、课堂派、无需在线跳转。平台网址统一维护在 `domain.js`，只保存平台标识，不填具体作业链接；列表与详情的“前往提交”打开对应平台网站，不会自动登录、提交作业或标记完成。旧作业缺少平台字段时不显示跳转按钮，可编辑后补选平台。

`courses.js` 固定记录本学期 11 门课程及已知其他大二课程，数分3、数学分析III、习概等别名归一化。无内容的课程保留入口并提示待补充；不推断其他课程的具体学期。资料支持课程、用途、格式、班级和关键词组合筛选，搜索覆盖附件名称；默认优先本学期，每次显示 24 条。同名但内容不同的版本保留为一条资料的多个附件，最多三个，多于三个拆分为文件组。

处理流程：`scripts/inventory-archive.ps1` 安全解压与 SHA-256 盘点；`scripts/audit-materials.ps1` 读取 PDF / DOCX 全文筛查疑点；`scripts/stage-materials.ps1` 保守复核、生成公开副本并清空 Word 作者元数据；`scripts/build-catalog.js` 生成规范资料目录。这些工具只接受明确的输入输出目录，不自动覆盖原件或发布远端。

333 个顶层文件中有 305 个不同内容，28 个完全重复。首批公开 44 个附件约 23 MB，其余 261 个不同文件留在本地待复核，包括个人作业、旧格式、扫描件、嵌套 ZIP / RAR、教材、出版题库、图片或嵌入对象疑点。不公开本地清单、正文提取结果、原始压缩包。自动疑点筛查不等同于内容审核、版权授权或安全保证，历史资料不代表本学期考试范围。
